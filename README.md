# chrome-extensions

## Packages
- [packages/tab-save-extension](packages/tab-save-extension) — [Tab-Save](https://chromewebstore.google.com/detail/tab-save/iphpjidhdoilnfjhjpchcgamknepmabh) Chrome extension for exporting/importing open tabs
- [packages/tab-save-server](packages/tab-save-server) — optional local server for automated tab backup
- [packages/websocket-test-client](packages/websocket-test-client) — [WebSocket Test Client](https://chromewebstore.google.com/detail/websocket-test-client/fgponpodhbmadfljofbimhhlengambbn) Chrome extension for testing WebSocket connections
- [packages/new-tab-to-url](packages/new-tab-to-url) — New Tab to URL Chrome extension for redirecting new tabs to any custom URL or local file

See each package's own README for setup and usage.
